# Examples

Two writing prompts outside the benchmark tasks. Each runs once without the
skill and once with it. With one run per side, the differences came down to
taste, so the main README shows a benchmark task instead.

[RESULTS.md](RESULTS.md) has the full outputs. Each example's `files/` folder is the project its session starts in.

Run them with:

```
bench/run.sh claude-opus-5-5 --eval-dir bench/examples --runs 1
```
