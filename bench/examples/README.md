# Examples

Two writing prompts outside the benchmark tasks, for the Before and After
section of the main README. Each runs once without the skill and once with it,
and the README shows both first attempts as they came out.

[RESULTS.md](RESULTS.md) has the full outputs. Each example's `files/` folder is the project its session starts in.

Run them with:

```
bench/run.sh claude-opus-5-5 --eval-dir bench/examples --runs 1
```
