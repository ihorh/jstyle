# CLAUDE.md

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing anything. It covers
the layout, commits, validation, versions, the text kept in sync, cold reads,
and the benchmark.

- **Load `/jstyle:write` for prose here:** the READMEs, the skill, the
  changelog, `docs/`, and reports. This repository uses its own skill.
- **Ask before running `bench/run.sh`.** A full run starts 60 paid sessions:
  10 tasks, each 3 times with the skill and 3 times without.
- **Leave `bench/runs/` as it is.** Each run is a record that reports cite.
- **Keep tracked files free of private context:** no private repository names,
  local paths, or personal notes.
