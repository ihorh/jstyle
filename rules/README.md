# Rules

The files in this folder aren't part of the plugin. Installing jstyle doesn't
copy them anywhere, and no session loads them unless you add them yourself.

[punctuation-and-case.md](punctuation-and-case.md) asks for the Oxford comma,
Chicago title case in headings, and punctuation that takes the style of the
text it belongs to. It gives way to any style the document or the project
already uses. If you like these conventions, put the file in your rules
folder, such as `~/.claude/rules/`, or paste it into a system prompt.
